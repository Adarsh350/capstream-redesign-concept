# CapStream Homepage Redesign Concept

An independent homepage redesign concept created by Iyara for CapStream.

The page reimagines CapStream's existing construction-finance positioning around a clearer story: one profile for surety bonding and project mobilization funding. It includes an original responsive visual system, a project-capacity model, mobile navigation, and an interactive mobilization-funding calculator.

This is a design proposal and is not an official CapStream website.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Quality checks

```bash
npm run lint
npm run build
```
